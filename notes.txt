Pontos de atenção nas views novas
- Sempre ler o envelope: resp["items"] e resp["total"], nunca len(resp) — o contrato paginado do backend.
- DELETE 204 não tem corpo: por isso os métodos de exclusão retornam bool, não resp.json() (httpx lança erro ao tentar parsear 204 vazio).
- Selects precisam da lista completa: o selectbox de "Conta superior" (só sintéticas) e o de "Plano de contas" (só analíticas) precisam buscar todos os registros, não só a primeira página. Use limit alto (listar_plano_contas(limit=1000)) e filtre no frontend. Vale conferir se o backend aceita limit alto sem teto.
- Erro de conexão: o _request re-levanta `httpx.
- RequestError. As views devem capturar e mostrar st.error("Servidor indisponível")` em vez de deixar o Streamlit exibir traceback.
- Mostrar a mensagem do 422: o backend devolve detail no corpo — exiba resp.json()["detail"] no st.error para o usuário ver a regra de negócio (ex.: "conta com filhos não pode ser excluída").
- Códigos de sucesso: criação → 201, atualização → 200, exclusão → 204. Depois de cada ação, st.rerun() para recarregar a listagem.

Implementação sistema de log (semelhante ao Logcat)

Nível|Equivalente Logcat|Quando Usar
---|---|---
DEBUG|Log.d()|Detalhes de desenvolvimento (ex: SQLs executados, payloads de requisição). Desativado em produção.
INFO|Log.i()|Eventos normais do sistema (ex: "Usuário X autenticado", "Título #123 criado com sucesso").
WARNING|Log.w()|Situações anômalas tratadas (ex: "Tentativa de login com e-mail não existente", "Token próximo de expirar").
ERROR|Log.e()|Erros de execução/exceções capturadas (ex: "Falha de conexão com SQLite", "Erro ao processar baixa").
CRITICAL|Log.f() (Fatal)|Falhas graves que derrubam o serviço ou impedem a API de subir.

PYTHON CLASSES

Um método estático é um método puro, não lê nem altera nada que pertença à classe/instância (ex: _get_headers1).
Já _get_headers2 não é um método estático pois acessa a propriedade `token`, asism o primeiro argumento tem que ser necessariamente `self`.

class APIClient:
    def __init__(self, base_url: str = "http://localhost:8000"):
        """construtor"""
        self.base_url = base_url
        self.token = None

    @property
    def token(self) -> str | None:
        """Busca dinamicamente o token JWT salvo na sessão do Streamlit."""
        return st.session_state.get("token")

    @staticmethod
    def _get_headers1() -> dict:
        """Monta os cabeçalhos das requisições injetando o Bearer Token se disponível."""
        headers = {"Content-Type": "application/json"}
        token = st.session_state.get("token")
        if token:
            headers["Authorization"] = f"Bearer {self.token}"
        return headers

    def _get_headers2(self) -> dict:
        """Monta os cabeçalhos das requisições injetando o Bearer Token se disponível."""
        headers = {"Content-Type": "application/json"}
        if self.token:
            headers["Authorization"] = f"Bearer {self.token}"
        return headers
